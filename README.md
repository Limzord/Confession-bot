to add my instance of this bot to your server, use this link:
https://bots.limzord.gay/acchan

## Installation
```bash
git clone https://git.tmmd.club/Limzord/Confession-bot.git
cd Confession-bot
python3 -m venv venv
source venv/bin/activate
python3 -m pip install -r requirements.txt
echo "<insert discord bot id>" > bot-id.txt
```
run (in repo directory):
```bash
source venv/bin/activate
python3 bot.py
```
